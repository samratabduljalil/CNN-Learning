Problem 1
Parameter explosion
Fully connected layers × image pixels = hundreds of millions of weights. Too slow, too large, overfits.
Problem 2
No spatial awareness
Flattening destroys 2D structure. Nearby pixels lose their relationship — edges become invisible.
Problem 3
Not translation invariant
A cat in the top-left vs center looks completely different. The network must relearn for every position.

Local receptive fields
Instead of connecting each neuron to every pixel, each CNN neuron looks at only a small local patch — typically 3×3 or 5×5 pixels. This is how biological vision works: retinal cells respond to local regions before combining into higher-level patterns.
Each highlighted cell = one neuron's receptive field (3×3 patch)
Solves: No spatial awareness — now each neuron explicitly looks at a spatial patch, preserving neighborhood relationships between pixels.
⚖️
Weight sharing (shared filters)
One filter (kernel) slides across the entire image using the same weights at every position. If a filter learns to detect a vertical edge, it detects that edge anywhere in the image — without relearning.
Parameter comparison — 224×224 color image, 64 output channels:
Plain NN (fully connected, 1 layer)9.7 billion
CNN (64 filters of 3×3×3 + bias)1,792
Solves: Parameter explosion + translation invariance — the same 1,792 weights detect the same features everywhere. ~5.4 million times fewer parameters.
📦
Pooling (spatial downsampling)
After convolution, a pooling layer shrinks the feature map by summarizing small regions. Max pooling keeps the strongest activation in each 2×2 patch. This reduces computation, adds robustness to small shifts, and lets deeper layers see larger context.
